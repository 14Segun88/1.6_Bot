# CS 1.6 Autonomous Self-Learning AI Agent 🤖🎯

Автономный самообучающийся ИИ-агент для Counter-Strike 1.6, построенный на базе компьютерного зрения (**YOLOv8**), чтения памяти движка GoldSrc и непрерывного онлайн-обучения с подкреплением (**Online Reinforcement Learning & Behavioral Cloning**).

## 🧠 Аудит выученных навыков нейросети (`cs16_policy.pt`, v3685)

За 8.5 часов и 124 000 сэмплов онлайн-RL демон провел **3 685 раундов градиентной оптимизации** (Loss снизился до `0.3085`).

### 1. Пространственное зонирование карты (Spatial Awareness)
Нейросеть выучила зависимость боевой готовности от позиции на карте `$2000$`:
* **Свой спавн ($Y = -1.8$):** Вероятность выстрела = **`0.0%`**. Огонь заблокирован для безопасности выбегающих союзников.
* **Центр арены ($Y = 0.0$):** Вероятность открытия огня взлетает до **`74.1%`**.
* **Смещение прицела:** В центре карты сеть держит горизонт `dy = -1.00`, сканируя проходы на уровне головы.

### 2. Вертикальный контроль отдачи (Recoil Pull-down)
* На кадрах с подтвержденными убийствами выходной вектор мыши `aim_head` выдает среднее смещение **`dy = +0.50 px`** (тяга прицела вниз при непрерывном огне).

### 3. Дисциплина перезарядки (Reload Discipline)
* В мирном беге вероятность `R` составляет **`42.6%`**.
* В момент боевого столкновения и фрагов вероятность перезарядки блокируется до **`32.0%`**, чтобы не остаться без оружия перед противником.

### 4. Боковая подвижность (Lateral Engagement)
* В фазе боевого контакта клавиши стрейфа `A` и `D` активны на **`92.3%`** и **`98.6%`**, модель обучается уклоняться от встречного огня.

### 5. Селекция "Свой / Чужой" (Zero Teamkill)
* Цветовая HSV/RGB-дискриминация скинов (Leet у T против GIGN у CT при `cl_minmodels 1`) полностью исключила огонь по союзникам за все 866 раундов.

## 🛠 Архитектура системы

* **`play_agent.py`** — основной высокопроизводительный исполнитель:
  * Детекция целей: **YOLOv8 Nano** на ONNX Runtime (< 8 мс на кадр).
  * Чтение состояния: WOW64 Toolhelp32 считывание координат и угла обзора из памяти `hl.exe`.
  * Плавное P-регулирование мыши без дерганий и овершута ($k_p = 0.80$).
  * Автоматический **Hot-Reload** весов каждые 4 секунды.
* **`self_learning_daemon.py`** — асинхронный демон онлайн-обучения:
  * Динамический буфер опыта `online_experiences.jsonl`.
  * Дисконтированный расчет наград $G_t = \sum \gamma^k r_{t+k}$ с фильтрацией холостого бега ($G_t > 0.025$).
  * Экспорт весов в чистый NumPy (`policy_weights.npz`) для ультрабыстрого инференса без GIL.
* **`evaluate_match_score.py`** — парсер логов сервера GoldSrc (`L*.log`) и автоматический расчет метрики $\text{Score}$.

## 🚀 Запуск и использование

### 1. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 2. Запуск полного контура игры и обучения
```cmd
START_ALL_IN_ONE_ARENA.bat
```
Либо вручную в двух терминалах:
```bash
# Терминал 1: Демон онлайн-обучения
python self_learning_daemon.py

# Терминал 2: ИИ-Агент
python play_agent.py
```

### 3. Расчет эффективности после любого матча
```bash
python evaluate_match_score.py
```
*(Скрипт автоматически находит свежий лог в `cstrike/logs/` и рассчитывает Score).*
