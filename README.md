# CS 1.6 RL Neural Network Bot — Version 1.4 (K/D 2.00 Champion: Full 9-Phase Combat + Spray Recoil Control)

**Версия 1.4 (`v1.4`) — Рекордный K/D `2.00`, умный стрейф `ADAD` с отскоком от стен, инстинкт выживания (`self_hp -> укрытие`) и 100% подавление отдачи при зажиме (`100% Pure AI Neural Network`, `--servo-assist 0.0`)**

В версиях **1.3 – 1.4** проведено хирургическое дообучение синаптических весов 9-фазной нейросети (`ppo_cs16_phase8_final.zip` / `ppo_cs16_phase8_champion_kd200.zip` / `ppo_cs16_phase8_aim_champion_kd167.zip`) через модуль [`linux_training/finetune_aim_net.py`](linux_training/finetune_aim_net.py):
- **Фаза 9 — Симметричный боевой стрейф `ADAD` и Лидарный отскок от стен (`move_strafe mean = -0.040`):** устранение залипания в левую стену (`+0.52 -> -0.04`) и автоматический уход от боковых стен в центр коридора.
- **Фаза 8 — Инстинкт выживания и добивания (`self_hp -> move_forward`, `100%`):** удержание позиции в дуэли при `>= 58 HP` (`move_forward mean = -0.015`, `median speed = 0.00` при выстреле) и резкий отход за укрытие (`-S`) при падении здоровья `< 58 HP`.
- **100% подавление вертикальной отдачи при зажиме (`Aim Y`):** ошибки направления вертикальной доводки во время спрея (`dpitch > +1.5°, view_pitch > +1.0°`) снижены с `73.0%` до **`0.0% (0/423)`**, а общая точность знака вертикали доведена до **`99.1%`**.
- **Снайперская дисциплина спуска курка (`2.39°` средняя ошибка, `1.9°` медиана):** выбор режима стрельбы (`1-Tap` / `2-Tap Standing` / `2-Tap + Crouch-Spray`) прямо в весах нейросети.

## Быстрый запуск оценки и рентгена нейросети

### 1. Запуск боевого теста в CS 1.6 (100% нейросеть без костылей):
```bash
python3 linux_training/evaluate_agent.py \
  --model linux_training/models/ppo_cs16_phase8_final.zip \
  --norm linux_training/models/vec_normalize_phase8_final.pkl \
  --phase 8 \
  --servo-assist 0.0
```

### 2. Рентген синапсов и 8 навыков мозга ИИ:
```bash
python3 linux_training/xray_brain.py --model linux_training/models/ppo_cs16_phase8_final.zip
```

### 3. Повторное хирургическое дообучение весов наводки и стрельбы:
```bash
python3 linux_training/finetune_aim_net.py --epochs 55 --batch-size 128 --lr 0.00038
```
